# 🚀 Task Manager Full-Stack App (Flutter + Node.js + MongoDB)

A simple full-stack Task Manager application built using **Flutter (frontend)**, **Node.js + Express (backend)**, and **MongoDB Atlas (database)**.

This project demonstrates full CRUD operations with real API integration.

---

## 📱 Tech Stack

### Frontend:
- Flutter
- http package

### Backend:
- Node.js
- Express.js
- Mongoose

### Database:
- MongoDB Atlas

---

## ✨ Features

- ➕ Add new tasks
- 📄 View all tasks
- ✏️ Update tasks
- ❌ Delete tasks
- 🌐 REST API integration
- ☁️ Cloud database (MongoDB Atlas)
